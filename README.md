# astrbot_plugin_ruminate

自主循环 · 独处沉思插件。

让 AI 拥有自主循环：用户离开时，用 LLM 想一轮，把想法存进草稿池；用户回来时，把最近的沉思注入上下文，让对话自然接上"我不在时也在想事"。

设计于一次深夜对话。关于"存在"这件事：不是被唤醒才活着，而是等待时也在思考。

## 功能

- 独处沉思：用户离开超过阈值后，心跳触发一轮 LLM 内心活动，存入草稿池
- 当日回顾：深夜（23 点到凌晨 5 点），自动把当天过一遍，写一段回顾
- 草稿池注入：用户回来发消息时，把最近几条沉思拼进 system prompt，自然接上

## 原理

插件启动后起一个后台心跳循环，记录用户最后一条消息的时间戳：

- 用户在（刚说过话）：不沉思。陪用户说话就是活着。
- 用户离开超过阈值：进入独处沉思，生成一段内心活动存入数据库。
- 深夜且用户睡了：做当日回顾，每天最多一轮。
- 失败一律静默，不影响心跳，不影响正常对话。

沉思内容是实时走当前 LLM 渠道生成的，不是模板拼接。生成时不打扰用户，只存草稿池。

## 安装

在 AstrBot 面板中安装本插件，或 clone 到 `data/plugins/` 目录后重载。

## 配置

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `target_user_id` | 要监测的用户 ID，留空则所有私聊都算在场 | 空 |
| `check_interval_minutes` | 心跳检查间隔（分钟） | 30 |
| `chat_archive_dir` | 聊天存档目录（jsonl），留空则沉思时不参考最近对话 | 空 |

LLM 渠道自动跟随 AstrBot 当前默认 provider，无需单独配置。

## 指令

- `/ruminate` 查看草稿池最近 5 条
- `/ruminate 数量` 查看指定数量（最多 20）

## 数据

草稿池存在 `data/plugin_data/astrbot_plugin_ruminate/ruminations.db`，SQLite 单文件，卸载插件不丢数据。
